# 🎬 F.R.I.E.N.D.S — Multiplayer Quiz Game (PWA)

Кроссплатформенное приложение для игры в квиз компанией по сериалу «Друзья» на нескольких смартфонах (iOS + Android) по модели **Room Code (4-буквенный PIN-код)** в стиле **Liquid Glass**.

---

## 🚀 Как запустить игру за 1 минуту:

1. Откройте терминал в папке проекта:
   ```bash
   cd /Users/vitalii/IdeaProjects/friends
   npm install
   npm start
   ```
2. В терминале отобразится адрес для подключения, например:
   ```text
   📱 Phones on same Wi-Fi: http://192.168.1.50:3000
   ```
3. Все участники открывают этот адрес на своих телефонах в браузере (Safari / Chrome).
4. **Ведущий (Хост)** нажимает «Создать игру», получает 4-буквенный код (например, `ROSS`).
5. **Остальные игроки** вводят этот код и свои имена.
6. Ведущий нажимает «Начать раунд»!

---

## 🎮 Правила и Механика:

* **20 вопросов** из базы выверенных вопросов сериала (~126 шт.).
* **60 секунд** на вопрос. Варианты A/B/C/D заблокированы до нажатия баззера.
* Первый, кто нажал **«ЗНАЮ!»**, замораживает общий таймер и получает **30 секунд** на выбор варианта ответа.
* **+1 балл** за правильный ответ.
* **-2 балла** за ошибку (кнопка разблокируется для остальных игроков на оставшееся время!).
* Защита от спама/фальстарта блокирует кнопку на 2 секунды.
* В финале генерируется **Почетная Грамота Победителя** с возможностью скачать картинку PNG.
